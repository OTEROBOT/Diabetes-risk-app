# เว็บแอปทำนายความเสี่ยงโรคเบาหวานด้วยการถดถอยโลจิสติก
React + Vite (frontend) · Flask (backend) · SQLite3 · scikit-learn · ส่งอีเมลผ่าน Brevo

## A. รันบนเครื่องตัวเอง (Python 3.10+ และ Node.js 18+)
    cd backend
    pip install -r requirements.txt
    python seed.py      # สร้าง admin + บทความ + ลงทะเบียนชุดข้อมูลจริง (BRFSS 2015, 70,692 แถว) + เทรนโมเดล 11 ตัวแปรให้อัตโนมัติ
    python app.py       # http://127.0.0.1:5000
เปิดอีกเทอร์มินัล:

    cd frontend
    npm install
    npm run dev         # http://localhost:5173
(หรือ `npm run build` แล้วเปิด http://127.0.0.1:5000 ได้เลย)  บัญชีเริ่มต้น: `admin / admin1234` (เปลี่ยนด้วย ADMIN_PASSWORD ก่อนรัน seed.py)
ถ้ายังไม่ตั้งค่าอีเมล ระบบจะแสดงลิงก์รีเซ็ตรหัสผ่านใน console/หน้าจอ (โหมดทดสอบ)

## B. ตั้งค่าส่งอีเมลจริงด้วย Brevo
1. สมัคร app.brevo.com → เมนู Senders, Domains → เพิ่มและยืนยัน "อีเมลผู้ส่ง" (ใช้อีเมลโดเมนของตัวเองจะส่งเข้ากล่องจดหมายได้ดีกว่า @gmail.com)
2. เมนู SMTP & API → API keys → สร้างคีย์ (ขึ้นต้น `xkeysib-`)
3. ตั้งตัวแปร `BREVO_API_KEY`, `MAIL_FROM_EMAIL` (อีเมลที่ยืนยันแล้ว), `APP_URL` (ที่อยู่เว็บจริง) ดูตัวอย่างใน `.env.example`
ระบบเรียก Brevo ผ่าน HTTPS (พอร์ต 443) จึงใช้ได้บน Render **ทุกแพ็กเกจ** ส่วนโหมด SMTP (`SMTP_HOST` ฯลฯ) **ใช้ไม่ได้บน Render แพ็กเกจฟรี** เพราะ Render บล็อกพอร์ต 25/465/587

## C. Deploy บน Render
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub → Render: New → Blueprint (อ่าน `render.yaml`) หรือ New Web Service เลือก Runtime = Docker
2. ตั้ง Environment: `ADMIN_PASSWORD`, `APP_URL` (เช่น https://ชื่อบริการ.onrender.com), `BREVO_API_KEY`, `MAIL_FROM_EMAIL`
3. **ข้อจำกัดแพ็กเกจฟรี:** ดิสก์ชั่วคราว ฐานข้อมูล SQLite (สมาชิก, ประวัติ, โมเดลที่เทรนใหม่) และรูปบทความที่อัปโหลดจะหายเมื่อรีสตาร์ต/ดีพลอยใหม่ (ระบบสร้างข้อมูลเริ่มต้นและโมเดลให้ใหม่ทุกครั้งที่เริ่ม) และบริการจะหลับเมื่อไม่มีผู้ใช้ ถ้าต้องการเก็บข้อมูลถาวร ใช้แพ็กเกจ Starter ขึ้นไป + เปิดส่วน `disk` ใน `render.yaml`

## D. ผลโมเดลเริ่มต้น
Logistic Regression, 11 ตัวแปรตามรายงาน, Train/Test 80/20, 5-Fold CV: Accuracy ≈ 74.5%, Recall ≈ 76.4%, AUC ≈ 0.82, CV ≈ 74.7%
Admin: Train Model → Test Model → ปุ่ม "ใช้งาน" เพื่อเปลี่ยนโมเดลที่ใช้ทำนาย (ชุดข้อมูลสมดุล 50/50 อยู่แล้ว SMOTE จึงแทบไม่เปลี่ยนผล)

## E. หมายเหตุการออกแบบ
- กลุ่มอายุ: 13 ระดับตามรหัส Age ของชุดข้อมูล (18-24 … 80+) ระบบรองรับอายุตั้งแต่ 18 ปี เพราะชุดข้อมูลไม่มีผู้ต่ำกว่า 18
- Probability = ความน่าจะเป็นจากโมเดล, Risk Score = ตำแหน่งความเสี่ยง (เปอร์เซ็นไทล์) เมื่อเทียบกับกลุ่มตัวอย่างที่ใช้ฝึก
- ผลทำนายเป็นการประเมินเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์
